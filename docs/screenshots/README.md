# Screenshots

README 里预留了截图位置，把图片放到这个目录即可。

建议至少两张（1920 宽左右，PNG 或 WebP）：

| 文件名 | 内容 |
| --- | --- |
| `overview.png` | 主界面全貌：温度源 + 风扇卡片 + 全局设置 |
| `curve.png` | 一张风扇卡片的特写，能看清曲线编辑器和拖动后的效果 |

放好之后把 `README.md` / `README.en.md` 里对应的注释块打开：

```markdown
![总览](docs/screenshots/overview.png)
![曲线编辑](docs/screenshots/curve.png)
```

> 截图前建议先把硬盘上的序列号之类的信息遮掉，或者只截取应用窗口本身。
